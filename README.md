# 📦 WarehouseApp — سیستم مدیریت انبار

یک برنامهٔ تحت وب برای مدیریت انبار، ساخته‌شده با **Blazor Web App (.NET 8)** و **SQL Server**، با رابط کاربری کامل فارسی و راست‌به‌چپ.

---

| بخش | توضیح |
|---|---|
| 📦 محصولات | افزودن، ویرایش، حذف + جست‌وجو + فیلتر دسته + صفحه‌بندی |
| 🗂️ دسته‌بندی‌ها | مدیریت کامل دسته‌ها و اتصال هر محصول به یک دسته |

## 🚀 اجرا

**گام یک — گرفتن مخزن:**

```powershell
git clone https://github.com/naderamani68/WarehouseApp.git
cd WarehouseApp
```

**گام دو — بررسی رشتهٔ اتصال پایگاه داده** در فایل زیر:

```
appsettings.json
```

مقدار پیش‌فرض:

```
Server=localhost;Database=WarehouseAppDb;Trusted_Connection=True;TrustServerCertificate=True;
```

**گام سه — بازیابی پکیج‌ها و ساخت پایگاه داده:**

```powershell
dotnet restore
dotnet ef database update
```

**گام چهار — اجرا:**

```powershell
dotnet run
```

**گام پنج — باز کردن در مرورگر:**

```
http://localhost:5023
```

## ⚠️ نکات مهم توسعه

- فایل‌های `.razor` و `.cs` که متن فارسی دارند باید با **UTF-8 with BOM** ذخیره شوند.
- هر صفحهٔ تعاملی باید `@rendermode InteractiveServer` داشته باشد.
- در اتصال به SQL Server از `localhost` استفاده کنید، نه نام نمونه.
- کامنت رازور (`@* *@`) را داخل تگ‌های اچ‌تی‌ام‌ال نگذارید؛ به‌جایش از کامنت اچ‌تی‌ام‌ال استفاده کنید.
- موجودی کل هر محصول از جمع حرکات انبار به دست می‌آید و در مدل محصول نگه‌داری می‌شود.
